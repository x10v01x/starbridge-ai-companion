星桥 AI 接入助手（Windows 10 / 11）

1. 将 ZIP 中所有文件解压到一个独立文件夹。
2. 双击 Start.cmd，使用本站账户登录。
3. 选择要使用的模型，点击“配置 WorkBuddy”。
4. 助手会生成备份并合并配置。保存任务后自行重启 WorkBuddy，选择带本站名称的自定义模型。

积分余额来自本站钱包，与 WorkBuddy 官方积分不同。
密码只用于登录本站，不会保存到磁盘。专属 API Key 会写入本机 WorkBuddy 配置，这是模型连接所必需的；请勿分享配置文件和备份。
客户端只访问 portal-profile.json 中的服务地址及服务端返回的模型地址。不修改 hosts、系统代理、注册表或官方账号积分，不会结束 WorkBuddy 进程。
程序运行需要 Windows 自带的 Windows PowerShell 5.1 和 .NET Framework。企业策略禁止脚本时，请联系 IT 或改用网页提供的手动配置。
当前版本未签名，不能保证绕过系统或企业安全策略，请仅运行从服务方正式页面获得并核实来源的文件。
恢复：在助手中点击“恢复最近备份”，先确认目标文件和备份信息。恢复会先额外备份当前配置。

在线支付尚未开通。目前使用兑换码充值，账户和兑换码由服务方发放。
